🔐 Batasan dan penggunaan aman

Tool ini ditujukan untuk analisis data publik, aset milik sendiri, troubleshooting, riset, dan pembelajaran. Gunakan hanya pada target yang boleh Anda analisis.

Tidak ada lookup database kependudukan privat, password, token rahasia, lokasi live seseorang, atau data pribadi yang tidak dipublikasikan. Browser juga dapat membatasi CORS dan rate limits.

🧪 Contoh workflow domain

  1. Masukkan example.com ke Domain.
  2. Periksa A/AAAA, MX, NS, TXT, CAA.
  3. Jalankan CT dan Subdomains.
  4. Periksa RDAP dan IP/ASN.
  5. Gunakan Headers/TLS jika target mengizinkan pembacaan browser.
  6. Simpan hasil penting ke Evidence.
  7. Catat perubahan di DNS Compare dan Timeline.
  8. Buat report.

🧰 Contoh workflow teks/log

  1. Paste log ke IOC Extractor.
  2. Normalisasi indikator dengan Target Normalizer.
  3. Gunakan Bulk Analyzer untuk beberapa target.
  4. Export IOC Table/CSV.
  5. Simpan source dan konteks di Evidence.

🧪 Hacker Lab Control Center

Fungsi: pusat navigasi tool keamanan defensif.

Cara: buka Hacker Lab → pilih tool → gunakan data sendiri/yang berwenang kamu audit.

Hasil: setiap analyzer menampilkan temuan dan batasannya.

Catatan: modul ini tidak menjalankan eksploitasi, pencurian credential, atau bypass akses.

📨 HTTP Request Parser

Fungsi: membaca method, path, host, header, dan body dari request mentah.

Input contoh: GET / HTTP/1.1 lalu header di bawahnya.

Langkah: paste request → PARSE REQUEST → periksa field yang ditemukan.

Batasan: parser tidak mengirim request dan tidak membuktikan keamanan server.

🧱 HTML Security Scanner

Fungsi: mencari pola seperti form tanpa HTTPS, inline event handler, iframe tanpa sandbox, mixed-content HTTP, dan target=_blank tanpa rel yang aman.

Langkah: paste HTML milikmu → SCAN HTML → review item REVIEW.

Hasil: indikator adalah checklist, bukan bukti exploit.

📦 Dependency Audit

Fungsi: membaca package.json secara lokal dan merangkum dependency production/development.

Langkah: paste JSON → AUDIT JSON → periksa jumlah package, versi, dan field script.

Batasan: tool tidak mengklaim package aman/vulnerable karena itu membutuhkan database advisory yang diperbarui.
